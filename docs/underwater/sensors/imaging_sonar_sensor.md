# 成像声呐

成像声呐有时也被称为前视声呐，它是一种多波束声呐，可以将声强投影到回波方位角二维平面上。这样就可以生成声呐前方区域的二维图像。成像声呐可用于探测声呐前方的物体，常用于自主水下航行器（AUV）探测前方障碍物。

请注意，“方位角条纹”参数用于控制模拟器是否在回波的方位角方向上添加或移除条纹，因为这些条纹是声呐图像中常见的伪影。

有关如何使用此传感器的示例，请参阅[可视化成像声呐](../example/sonar_imaging.md)。

有关 Python API，请参阅 [ImagingSonar](https://openhutb.github.io/doc/python_api/#holoocean.sensors.ImagingSonar)。
